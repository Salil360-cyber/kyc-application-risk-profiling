Application Risk Profiling

Nine red-flag rules score 30,000 bank account applications into Low, Medium, High and Critical tiers, so reviewers see the riskiest cases first. Change any rule below and the whole review queue is re-scored on the real sample.

Rule check

Does each red flag actually find fraud?

Lift = fraud rate among flagged applications divided by the overall rate. Below 1.0x (dashed line) the flag finds fraud less often than picking at random, so it should not add points.

Data: Bank Account Fraud (BAF) Suite, NeurIPS 2022, working sample of 30,000 synthetic applications (363 fraud cases). The label is account-opening fraud, not a KYC outcome. Age, income and employment are not used in the score.
The score sets the order of review; it does not decide an application. Code and workbook: github.com/Salil360-cyber/kyc-application-risk-profiling · Salil Gokhale
